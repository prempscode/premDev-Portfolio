# premDev Portfolio

My personal developer portfolio website, built to showcase my projects, skills, and experience.

🔗 **Live site:** [premdev-mu.vercel.app](https://premdev-mu.vercel.app)

> Used AI for creating it

## Tech Stack

- **Vite** – build tool and dev server
- **Tailwind CSS** – styling
- **PostCSS** – CSS processing
- **ESLint** – code linting
- **API routes** – backend/serverless functions (`/api`)
 
## Project Structure

```
premDev-Portfolio/
├── api/              # Backend/API routes
├── public/images/    # Static image assets
├── src/              # Source code (components, pages, etc.)
├── index.html
├── package.json
├── tailwind.config.js
├── vite.config.js
└── postcss.config.js
```
